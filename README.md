### 👨‍💻 About Me

- ☕ **Core Backend:** Developing high-performance RESTful APIs and distributed systems using **Java** & **Spring Boot**.
- 🔒 **Security:** Implementing authentication and authorization with **Spring Security**, JWT, and role-based access control (RBAC).
- 🤖 **AI Integration:** Building intelligent backends and LLM workflows using **Spring AI** and Hugging Face.
- 🗄️ **Databases & Persistence:** Production databases with **PostgreSQL**, in-memory testing with **H2**, and schema migrations via **Flyway**.
- 🧪 **Testing & Quality:** Writing reliable integration tests with **Testcontainers**, **JUnit 5**, and **Mockito**.
- 🐳 **DevOps & Cloud:** Containerization with **Docker**, continuous delivery with **GitHub Actions**, and deployment on **AWS EC2**.
